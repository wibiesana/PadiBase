Quick Guide to PadiBase Studio

PocketBase & Supabase Simplicity

1 1. Tables & Spreadsheets

Click any table in the left sidebar to view its records. Click any row or + New Record to open the slide-over drawer to view or edit fields.

2 2. Edit Table Schema & Access Rules

Click Edit Table in the header to add or rename columns, configure foreign keys, or customize API access rules (Public, Auth Required, Admin Only).

3 3. API Preview & Custom API

Click API Preview to see curl and JS SDK snippets for the active table. Or use Custom API in the left rail to create custom dynamic queries.
