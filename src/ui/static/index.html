Quick Guide to PadiBase Dashboard

            
3 Easy Steps to Manage Databases & API Settings

          

        

        
      

      

        

          

            1
            1. Select, Create, or Sync Tables
          

          
Use the left sidebar to select a table. If your database (SQLite/MySQL/PostgreSQL) already has existing tables, click Sync Tables from Database to automatically register them in the dashboard.

        


        

          

            2
            2. Configure Table Settings with 1 Click
          

          
At the top of the table workspace, click Realtime: ON/OFF or Auto Relations: ON/OFF to toggle features instantly. To configure permissions (Public or Authenticated), switch to the Settings, Schema & Access Rules tab.

        


        

          

            3
            3. Global Table Matrix & Backups
          

          
Want to manage multiple tables at once? Click Settings & System in the top header to access the All Tables Matrix, application configuration, and Database Backup & Restore.
